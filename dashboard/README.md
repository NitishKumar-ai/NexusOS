# NexusOS Dashboard

This is the delivery layer for NexusOS Agent Mission Control. It provides a Perplexity-inspired interface for commanding and monitoring AI agents.

## Built With
- **Next.js 14** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **Premium Design System** (Glassmorphism + Dark Mode)

## Getting Started

1. Install dependencies:
   ```bash
   pnpm install
   ```
2. Start the development server:
   ```bash
   pnpm dev
   ```
3. Open [http://localhost:3000](http://localhost:3000) (or the port specified in the console).

## Key Components
- `CommandBar`: Central input for agent tasks.
- `LiveFeed`: Real-time mission stream for pipeline observation.
